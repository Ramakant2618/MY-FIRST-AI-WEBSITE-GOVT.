# JanSahayak AI — SISTec Innovation Hackathon 4.0 (IS-9)

## Run on Windows

1. Extract this ZIP.
2. Open CMD/Terminal inside the extracted `JanSahayak_AI_IS9_COMPLETE_FIXED` folder.
3. Run:
   `npm install`
4. Then run:
   `npm start`
5. Open:
   `http://localhost:3000`

## Folder structure

- `server.js` — Express server
- `package.json` — Node dependencies and start command
- `public/index.html` — UI
- `public/app.js` — app logic and scheme data
- `public/style.css` — complete styling

The demo profile and saved schemes use browser localStorage. Social/WhatsApp login is a frontend demo flow; production OAuth/OTP providers still need backend credentials and verification.
